115 海报墙重命名助手
====================

一、启动
  双击 AutoRename115.exe。
  首次启动（还没有登录 Cookie）会先弹出 115 风控提醒：不要频繁刷新、
  连续分析/改名或快速重复点击，否则可能出现手机端能登录、电脑/电视端
  暂时看不到文件的情况。提醒窗口可勾选“只显示一次”；取消勾选则下次
  启动还会提示。关闭提醒后才会打开扫码窗口。
  也可以关闭扫码窗口，点“演示模式”先看效果。
  如果 Windows 提示“已保护你的电脑”，点“更多信息”→“仍要运行”。

二、登录
  1. 用手机 115 App 扫二维码，手机上确认。
  2. 二维码过期就点“刷新二维码”。
  3. 扫码一次后会记住登录：Cookie 同时保存在程序目录和
     %APPDATA%\AutoRename115，换新版本/换解压目录也不用重扫。
  4. 登录设备默认 ios（不影响安卓手机/网页登录）；android 可能踢掉手机 App，
     web 可能踢掉网页登录且会话较短。同一设备类型会互相踢下线。
     如果提示登录过期，再扫一次即可，也可以在设置里换登录设备。
  也可以“导入 Cookie”（需要 UID / CID / SEID / KID）。

三、使用
  1. 左侧双击文件夹进入；左键拖动可连续多选，Ctrl+单击可单独加/减，
     Shift+单击可连选。标题栏会显示“已选 N 项”。
     右键单个文件/文件夹可“重命名此项（立即生效）…”，也可以按 F2；
     只改这一项，文件的扩展名不能改，改名立即写入 115，可用
     “撤销上一次”恢复。右键菜单还能进入文件夹、分析选中、刷新目录。
  2. 选中剧集/电影根目录，点“分析选中”或“分析当前目录”。
     分析会同时读取当前文件夹和上级文件夹名。即使目录里只剩
     00001.m2ts、00002.m2ts 这类纯编号视频，也会按编号识别成
     S01E01、S01E02…；ass/sup 字幕目录会自动跟着对应。
     季目录名前面带剧名/年份/规格也能识别，例如
     “Overlord 2015 S01 JPN Blu-ray 1080p”会归到 S01；
     “S2-美版暂无日语字幕sup”“S1替换双语字幕”这种“季号+说明”
     目录也会归到对应季，不会把说明文字当成另一部剧。
     季目录本身不一定是片名：片名会继续从上级、上上级目录兜底；
     都没有就留空并标“需确认”，不会拿“S1替换…”或字幕文件名去搜索。
     如果季目录里的视频文件名和上级剧名明显对不上（例如放错目录），
     自动匹配会先停下并标“需确认”，不会把整季改成文件里那部剧。
     “剧版《剑尘道魔录之玄劫天锋 2019》”这类目录，“剧版”只是
     版本说明，会用括号里的真剧名和年份搜索，不会拿“剧版”去搜。
     如果剧集根目录里同时有 S01-S04 季目录和剧场版 ISO，会拆成
     剧集任务和电影任务；剧集根目录不会再被误判成电影。
     分类会结合所在文件夹（动画/美漫/美国动画/电视剧/电影/剧）、
     Bangumi 的地区标签（美国/美漫/美国动画）和 TMDB 的动画类型；
     美国动画归为“美漫”，英国/加拿大等归为“欧美动画”，两者命名
     规则相同；电视剧目录下的真人剧不会再被归成动画。
     目录里有 tvshow.nfo / movie.nfo（或与视频同名的 .nfo）时，
     会优先读取其中的 TMDB/IMDb ID、标题和年份作为刮削锚点；
     读取失败或没有 ID 时仍按原来的方式搜索。
     同一部剧/电影有多个版本目录时，主版本保留原名，额外版本的
     文件夹名在 ID 前加 V2/V3；文件夹里的视频仍正常命名。
     合集目录里混放电影和季目录时，即使季目录名没写 S01/S02，
     只要子目录里有两个以上集号文件，也会单独分析，并按文件里的
     S1E01/S2E01 给文件夹补上 S01/S02；最外层合集目录保持原名。
     OAD/SP/OVA/特别篇/Specials 目录里的文件没有集数时，会先按
     TMDB 第 0 季特别篇标题匹配成 S00E01、S00E02…。
     任意目录里的 SxxE00 会按特别篇“第0话”映射为 S00E01；
     带 [Special]/OVA/OAD/特别篇 标记但没有真正集号的文件（包括
     蓝光 ISO）也会进入特别篇匹配，例如 S1E00 -> S00E01、
     [Special] ISO -> S00E02。字幕/音轨会跟着改。
     匹配不到才按文件名顺序补号。只剩一个文件、且只剩一个未用
     集号时直接补上并保持自动；仍有歧义才标“需确认”。
  3. 右侧看结果：
     进度条在“等待处理的任务”右侧，按“扫描/联网查询 → 重命名 →
     NFO/图片上传”分阶段显示真实 x/y；总数未知时只显示阶段文字。
     登录、设置、手动搜索、改名、预览等弹窗都会在父窗口中央打开。
     - 绿色“自动”默认勾选；橙色“需确认”默认不勾选。
     - 点一行，在下方可以改标题/年份/季/分类。
     - “影片资料”里用单选按钮切换 豆瓣 / Bangumi / IMDb / TMDB，
       查看评分、封面、简介和演员；不是下拉框。
     - 例如“进击的巨人 最终季 Part.2”：在“季”填 4，点“重新生成预览”。
     - 季号支持 S02、第二季、Season II、Ⅱ、第Ⅱ部、Part II 等写法。
     - 蓝光 BDMV 目录只会改最外层文件夹，内部 BDMV/STREAM 不动，
       状态是“需确认”；可用“全选有操作的”批量选中。
     - 自动匹配不对或没找到时，点“手动搜索”（也可以右键任务 →
       “手动搜索正确条目”）：输入片名，点“搜索”会同时查询
       豆瓣/Bangumi/IMDb/TMDB，双击结果即可替换标题、年份和 ID；
       程序会尽量补齐 IMDb/TMDB 标识。
       搜索窗口上方会列出拆分好的关键词（中文名、副标题、英文名、
       S02/第二季/Season 2 等），用普通文字排成一行（·分隔），
       点一下就能换词搜索。本地目录名优先：例如
       “攻壳机动队 SAC 2045”会完整保留，不会只剩“攻壳机动队”；
       01.m2ts/02.m2ts 这类文件序号不会混进关键词。自动匹配的
       英文名/别名只有和本地标题对得上时才补充，匹配错的不会带偏。
       选中结果后下方会显示类型、地区、首播/上映日期、评分和简介，
       方便区分同名影片。
       豆瓣 / Bangumi / IMDb / TMDB 四个来源固定显示成按钮，按钮上带
       结果数量；点 IMDb 就只看 IMDb 的结果，点“全部”恢复。搜索会同时
       查询全部可用来源，切来源只过滤显示，不重新联网。
       搜索结果上方还可以按类型（剧集/电影/未知）、内容（动画/真人/未知）、
       地区筛选；结果表会显示“内容/地区”两列。来源没给出明确信息时
       留空，不会乱猜；提示行会显示被隐藏的未知项数量，可把对应筛选
       切到“未知”查看。Bangumi 结果会自动补详情（30 天缓存），补出
       地区并识别剧场版。点“重置筛选”恢复全部。
       程序会用 TMDB 季集数校验：有 Sxx 但集号超出该季集数会提示；
       没有季标记且集号超过第一季集数时，会标记“需确认”并暂停
       集数改名，避免把总集编号误写成 S01E13。填好季号后重新生成预览。
       选中剧集任务后，详情里的“季集映射…”可以逐文件修改季/集，
       也可以“总集数自动分季”，按 TMDB 各季集数把 E13 分到 S02E01；
       多版本用蓝色、疑似重复用红色标出。该功能只重建预览，不会直接
       改网盘。同一目录内同集多文件且规格不同时才临时加 v2 防撞名；
       规格相同的按疑似重复处理，任务会变成“需确认”。
     - 自动搜索和手动搜索都带模糊匹配：会同时搜主标题、英文名和
       第N季/Season N 等变体；豆瓣结果不全时会读取豆瓣搜索页补全四季，
       并优先选中当前任务对应的季。
       自动候选还必须和本地标题/别名有真实文字重合，完全同名优先；
       电影候选年份差超过 1 年先排除。只靠“剧版/影版/第一季”这类
       前缀拿到的高分不会被采用，没有合格候选时会停下标“需确认”。
  4. 点“预览操作”核对旧名 → 新名。预览列表最前面有“选”列，
     默认全选；点一下可单独取消某个文件夹/文件，底部有“已选 N/M”
     和“全选/全不选”。应用时只改勾选的项目，没勾选的保持原名；
     自动保存 NFO/图片也只跟随勾选的项目。
  5. 勾选要改的行，点“应用选中重命名”，确认。
     如果事先勾选了详情里的“应用改名后自动存 NFO/图片”，
     改名成功后会接着自动生成并上传 NFO/图片，不用改完再找任务；
     有改名失败项的任务会跳过自动保存，并在提示里说明。
  6. 需要 NFO/图片时，也可以手动点“保存 NFO/图片”：
     - 剧集会生成 tvshow.nfo、每集同名 .nfo、poster.jpg、fanart.jpg；
     - 设置里的“已有 NFO/图片”可选：跟随媒体改名 / 删除后重存；
     - 只补齐缺失文件，上传到 115 对应文件夹。
     “应用改名后自动存 NFO/图片”勾选后会记住，下次启动仍然有效；
     不想自动保存时取消勾选即可。
     点“清空 NFO/图片…”可选：
       · 所选任务：只清与当前任务匹配的 NFO/图片；
       · 当前文件夹：按文件夹里的视频名匹配。
     两者都只移到 115 回收站（可恢复）；电影库根目录有多部电影时，
     不会因为清一部而误删其他电影的资料。
  7. 改错了点“撤销上一次”。
  8. 右侧任务是“等待处理”列表；不想处理某一项时，右键它 →
     “从等待列表移除”（只清界面，不会动网盘），也可以按 Delete 键。
     右键菜单里还有“清空等待列表”。
  9. 想单独改某个名字、不跑批量规则：右键任务 →
     “临时改名（立即生效）”，选一项、改好名字后点“立即改名”。
     会马上修改 115 上的名字，只改这一项，不删除、不移动。

四、命名规则
  - 日本番剧：葬送のフリーレン S01E01.副标题.mkv
    （视频文件名用日文原名；没有日文时用罗马音/英文名；不写规格。
      副标题取原文件名或 TMDB 单集标题，没有就省略。）
  - 电视剧/国产动画/美漫/欧美动画：
      中文名.英文名.S02E01.副标题 [2160p WEB-DL].mkv
    副标题优先取原文件名 SxxExx 后面的文字；原文件名没有时用 TMDB
    单集标题；都没有就省略这一段。英文名没有时也省略。
    规格尽量保留：分辨率、HDR/HDR10+/DV、编码、位深、音频编码、声道、
    fps、BT.2020/DCI-P3 等。
  - 电影/动画电影/剧场版：
    保留原名称和规格，只在中文名或带 [] 的中文名后面插入 ID：
      朝花夕拾 → 朝花夕拾[imdbid-tt...]
      [朝花夕拾] → [朝花夕拾][imdbid-tt...]
      [朝花夕拾 2018] → [朝花夕拾 2018][imdbid-tt...]
    原文件名里已有的 ID（不在中文名后面）会先删掉，再放到中文名后。
    其他规格文字保持不变；ID 写法按设置里的“标识写法”。
  - 原目录/文件名里已有 [imdbid-...] / {tmdbid-...} 时，会先用这个号
    查 TMDB 确认标题和年份（IMDb 号会反查）。ID 只作为查元数据的依据，
    不会阻止后续按上面的规则改名。
  - 剧集文件夹统一为：中文名 英文名 Sxx (首播年份) [ID]
    例如：假如...? What If S02 (2021) [tmdbid-91363]
    没有英文名时省略英文；日番仍按 中文名 日文名 的风格。
    美漫同样使用中英名 + 副标题 + 规格；设置里的 Bangumi 辅助识别
    也会读取“美国/美漫/美国动画”标签，把美国动画归到“美漫”分类。
  - 剧集的中英文名和主剧 ID 强制使用联网元数据；联网没拿到剧名时
    任务会标记“需确认”，不会拿本地文件名猜一个名字硬改。
  - 日番文件夹可选你的风格：
      [BD-REMUX]中文名 日文名 (年份) [imdbid-tt...]
      或  中文名 日文名 (年份) [imdbid-tt...] [BD-REMUX]
    启用“日番文件夹风格”时统一用 [BD-REMUX] 开头；原目录的
    [BDMV]/[BDISO]/[BDRip] 只作为来源说明，不会搬到新名字开头。
    命名前会先读原目录/文件名里的中文、日文、英文名：已经有第二语言名时
    直接用，不再联网取该名称；
    原目录同时有年份和 ID 时，整部剧完全不联网。都没有时才查
    Bangumi/IMDb/TMDB（日文优先，其次英文）。
  - 季目录：Season 01 / Season 02 / Specials
  - 单独分析某一季（如 S02、第二季、Season 2）时，剧集文件夹名会在
    中文名后加季号：降世神通：最后的气宗 S02 (2005) [imdbid-tt...]
    整部剧根目录（里面有多个季子目录）仍保持：中文名 (年份) [ID]
  - 字幕/音轨跟随视频改名，保留 .zh/.chs 等后缀。
  - 目录名里原有的 {tmdbid-...} / [imdbid-...] 会先核对标题；对得上才保留，
    明显是别的剧/季的 ID 会忽略，改用主剧 ID。

五、安全
  - 默认只重命名，不移动、不下载。
  - NFO/图片默认只有点“保存 NFO/图片”才会上传；如果勾选了
    “应用改名后自动存 NFO/图片”，应用改名确认并成功后会一并上传。
    清空操作会移到 115 回收站，不永久删除，执行前都会确认。
  - 115 风控保护：程序会主动放慢请求（读取约 0.45 秒、写入约 1.15 秒，
    每批最多改 10 项，NFO/图片每个约 1.3 秒）。如果 115 提示“操作频繁/
    触发风控”，会立刻停止后续批次并冷却约 60 秒，期间不再请求 115；
    同一会话再次触发会延长冷却并继续放慢。
    网络抖动不会被误判成登录失效；只有 115 明确返回登录失效才会提示重扫。
  - 115 同一设备类型会互踢。如果反复被踢下线，请在登录窗口换一个
    设备类型（例如 ios ↔ web）重新扫码。
  - 重命名本身不新建文件夹。
  - 扩展名不变。
  - 每次应用都有撤销记录（最近 20 次）。
  - 演示模式不联网、不改网盘。

六、海报墙建议
  - Jellyfin：库语言设 zh-CN；最佳方式是填 TMDB API Key，
    设置里标识优先级选 auto/tmdb。IMDb 标识需要 OMDb 插件。
  - 设置窗口里 TMDB API Key 输入框下方的“获取 TMDB API Key”
    可以直接打开官网申请页：https://www.themoviedb.org/settings/api
  - Emby：标识写法选 emby。
  - Plex：标识写法选 plex。

七、数据位置
  程序旁边的 data/ 目录：
    cookies.json         登录 Cookie
    metadata_cache.json  查询缓存（可删）
    undo.json            撤销记录
    settings.json        设置
    error.log            启动错误日志（如果有）

八、注意
  - 豆瓣可能限流；程序会降速并用 Bangumi/IMDb 兜底。
  - “最终季/Part.2”无法自动知道第几季，需要手动填季。
  - 蓝光 BDMV/VIDEO_TS 目录结构暂不支持；ISO/M2TS/MKV/MP4 单文件正常。
  - 只选中 Season 目录时，不会改上级剧集文件夹名；建议选剧集根目录。
